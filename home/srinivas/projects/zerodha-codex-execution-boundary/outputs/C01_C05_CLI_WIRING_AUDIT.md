# C01/C05 experimental CLI composition

Copied latest primary `scripts/run_r5_paper_lifecycle.py` and `tests/test_r5_paper_lifecycle_entry.py` into this isolated snapshot before edits. Added CLI options:

- `--acceptance`: selects native C05 factory with passive side accounting/full native reports and durable runtime receipts under the run's `acceptance/` directory.
- `--fleet-loading`: requires acceptance and instantiates explicit `FleetLoadingPolicy(enabled=True)` prototype defaults. Manifest records untuned classification, complete policy values/identity and loaded source path/hash.
- `--feedback-compaction`: requires acceptance and invokes C04's PaperStateJournal feedback-compaction mode. Manifest records loaded journal source path/hash.

Default selection remains the ordinary worker execute_block path. CLI factory selection does not use the executor test seam; fixed v2 protocol hash, source ancestry, critical loaded module attribution, midrun source freeze, frozen registry/input universe, Stage B Block 1 and isolated new output/WAL guards remain enforced. Explicit `--acceptance` plus injected executor is refused. Private programmatic loader substitution remains labelled test-only and never certifies actual48 coverage. Optional factory/fleet/journal modules must be loaded inside the selected checkout; missing integrated C02/C04 APIs fail explicitly.

Acceptance summary adds actual passive ID/governor/first-pre-submit-reject/Gate12 reached accounting, actual safety values, holding-bar and elapsed-minute Q1/median/Q3, gross R mean from engine P&L divided by initial fill-to-stop risk times quantity, and engine costs/friction. Gross R is unavailable unless every completed trade has a nonzero known initial stop. Bars and elapsed minutes are independently sourced; overnight wall-clock elapsed minutes are not represented as bars.

Includes unsupported/live options, missing option dependencies, fixed protocol hash guard under acceptance, original default behavior and actual native TITAN factory run producing full reports, holding metrics and counter summary.
