# C05 native experimental acceptance factory

The new `scripts/diagnostics/r5_block1_acceptance.py.execute_block` reuses sealed worker prepare_block (or explicit separated-data prepare callback), frozen registry verification, payload validation, grid provider, native CentralPlantMasterDCS, existing paper CombinedCycleRuntime factory, actual orchestrator.run and existing metrics/canonical fingerprint functions. It is explicitly Block 1 only and requires a separate output path; it never modifies the sealed worker, classes globally, parameters, data, or engine decisions.

Returns worker-compatible audit/metrics/plant_control/governor_authority/micom/trades/block_fingerprint fields plus passive counters, safety contract and full-report paths. Saves native_report.json, passive_rejection_accounting.json, runtime_safety_contract.json, runtime_receipts.json, acceptance_result.json. SQLite runtime payloads retain all position records (including CLOSED) and conversion receipts before the store is closed. Native report contains the engine's own MTM/drawdown and gross/net/friction data.

Passive instance wrappers capture bound originals, call each exactly once and return the same object: ID evaluate, governor entry, final pre-submit. ID warmup is separately labelled ID_WARMUP; native ID is ID. Pre-submit rejection is the actual first rejecting gate/reason from the returned result. GATE12_REACHED counts only actual returned Gate12 decisions; earlier gate rejection never counts as Gate12 input. Each side/stage has `input = passed + sum(rejects)` verified. Governor counters describe decision outcomes; for full governor these are admission outcomes, while advisory governor outcomes are telemetry only. Side on pre-submit is inferred from actual target versus entry geometry because EntrySignal has no side field. Native report/funnel still captures other upstream/downstream vetoes outside these requested stages.

Optional FleetLoadingPolicy is imported lazily and passed only when its constructor kwarg exists. Unsupported loaded source fails explicitly. Optional feedback_compaction uses the integrated PaperStateJournal(path, feedback_compaction=True), and rejects source without that API. Both features require root's separately reviewed integrated modules; this isolated factory checkout has neither enabled during the fixture parity test.

Verification: `python -m pytest -q tests/test_r5_block1_acceptance_counters.py`: 3 passed, 64 warnings, 9.42s. Two focused accounting/identity tests plus a real TITAN-derived normal replay through this actual factory compare the entire trade ledger to the uninstrumented normal orchestration path. One real SELL trade equals baseline exactly; all accounting closes; runtime CLOSED position persisted; live admission false. This is a one-symbol fixture regression, not the 48-symbol acceptance result. Full48 run must be executed by root after aggregate integration with source/input manifest hashes.

Integration: the C01 runner executor port should call this function with `output_path` to its per-run artifact directory and `prepare` bound to C01 separated-stock/grid root preparation. Do not redirect or patch the sealed worker globally.
